# landing3d

Código do palco 3D da landing (carro do pacote ORBO: Aston Martin DB11, CC-BY 4.0, crédito no rodapé).
O resultado do build é `public/landing3d/landing3d.js`, servido pelo Express; o modelo fica em `public/modelo/db11.glb`.

```bash
cd landing3d
npm install
npm run build
```

A cena só liga com WebGL, sem movimento reduzido e com o texto no tamanho padrão; senão a página mostra a versão em lista.
